# Instagram Reels / Threads 공통 분석 연결

종목 선정과 원본 AI 분석은 기존 `generateDailyInstagramAnalysis`가 평일 10시, 14시, 17시(KST)에 한 번 수행한다. `_admin/instagramAutomation/jobs/{day_market_ticker}`에 원본을 먼저 저장하며, `sharedAnalysisReady`, `analysisId`, `analysisHash`로 준비 상태와 동일성을 확인한다.

두 채널의 편집과 디자인은 각각 유지한다.

- Instagram: 다른 노트북의 ac6967f에서 가져온 기존 릴스 편집기, Wanted Sans, 1080x1920, 하단 370px 여백, 음악 및 영상 구성.
- Threads: 기존 반말 설명과 질문, 고정 첫 문장, 설치 링크, 사진 두 장, 점수 구간별 색상, 이전 글에 이어지는 답글. 본문 마지막 안내 문구 제거도 유지한다.

원본 저장 뒤 Instagram은 릴스를 제작하고 게시한다. Threads는 20분마다 같은 원본을 읽어 게시한다. 동시 게시를 보장하는 구조는 아니며, 분석 내용과 종목을 일치시킨다. 릴스 제작이나 게시 실패가 Threads를 막지 않는다. Instagram 재시도는 저장된 원본을 재사용하므로 두 채널의 분석이 달라지지 않는다. 채널별 표현을 만드는 편집 AI 호출은 별도이며, 종목 원본 분석만 공통이다.

기존 작업 문서를 보존하고, 게시 완료/게시 응답 불확실 상태는 재게시하지 않는다. 과거 날짜, 12시간 이상 지난 분석, 초안 전용 작업 및 해시가 달라진 원본은 Threads에서 제외한다. 기존 저장 분석도 호환하며 별도의 일괄 재게시를 실행하지 않는다.

검증: 원본 생성 1회와 재시도 재사용, 원본 변경/오래된 데이터 거절, Instagram 실패 상태에서 Threads의 동일 원본 소비, 각 채널 게시 중복 방지와 기존 디자인 테스트를 포함한 39개 테스트가 통과했다.
