# 자유게시판 캐릭터 비공개 테스트

실행: `node tools/community_bot_lab.cjs --seed 42 --days 7 --start 2026-09-11`

결과: `output/community-bot-lab/index.html`, `simulation.json`.
같은 시드는 같은 일정을 만들고, 시드를 바꾸면 활동 날짜와 시각이 달라진다.
기존 결과 파일은 재실행 시 교체된다. 실제 게시판/계정과 연결되지 않는다.

## 포함된 기능

- 고정 ID를 가진 합성 캐릭터 50개와 서로 다른 글 예시 50개. 일반 닉네임과 주식 관련 닉네임을 섞는다.
- 미리보기 구성은 주식 이야기 30개, 주식 잡담 10개, 일상 잡담 10개. 실제 사이트를 집계한 통계가 아닌 편집용 테스트 비율이다.
- 반도체, 바이오, 배당, ETF, 공시, 재무제표, 밸류에이션, 차트, 매매복기, 거시경제, 조선·방산, 배터리·소재, 미국주식, 리스크관리, 주식기초의 15개 관심 분야. 같은 분야 안에서도 관찰 초점이 다르다.
- 개인별 관심사, 문체, 태도, KST 활동 시간, 일 활동 확률, 주말 가중치, 최소 게시 간격.
- 관심 업종과 게시글 소재는 별도다. 개인별 잡담 확률과 주말 가중치로 예정 글의 분류도 달라진다. 주말에 일상 글을 억지로 투자 교훈에 연결하지 않는다.
- 기간 중 활동하지 않는 캐릭터와 변동하는 일별 전체 글 수.
- 개인별 하루 최대 한 번, 기본 전체 하루 최대 12번의 모의 게시.
- 현재 앱 소스의 글당 경험치와 레벨 기준을 읽어 적용. 글마다 XP가 증가하고 임계점을 넘으면 레벨이 오른다.
- 최근 주제 최대 5개를 포함한 초안 생성 프롬프트. 실제 생성된 글의 장기 기억 기능은 아직 아니다.
- 검색, 관심사 필터, 문체/활동 보기 전환, 캐릭터 정보 및 작성 지침 펼치기.

## 테스트 범위

샘플은 이번 테스트용 고정 작문이다. LLM 자동 생성, 실제 뉴스 조회, 댓글/좋아요,
계정 생성, Firebase 저장, 예약 게시를 구현하거나 실행하지 않았다.
일정의 `simulated_only`는 실제 게시 성공을 의미하지 않는다. XP도 로컬 모의 값이다.
프롬프트만으로 반복/모순 방지가 검증된 것은 아니다. 다음 단계의 생성 결과 평가가 필요하다.

회귀 검사: `node --test tools/community_bot_lab.test.cjs`.

실제 이용자의 닉네임, 글 본문, 개인 이력을 복제하지 않았으며 특정 이용자 사칭용 프로필이 아니다.
