# 웹 기능 점검 및 개선 — 2026-09-10

## 범위

기존 웹 계획의 8개 메뉴와 로그인, 초기 실행, 광고·결제 연결, 외부 시세 요청을 코드와 로컬 릴리스 웹 빌드로 점검했다. 실제 사용자 로그인, 글 작성·업로드, 비밀번호 재설정 메일 발송, 유료 AI 생성은 실행하지 않았다. 인증 변경은 가짜 FirebaseAuth/AuthService를 사용하는 위젯 테스트로 검증했다. 운영 배포는 하지 않았다.

## 반영한 개선

| 문제 | 변경 |
|---|---|
| 일반 사용자 로그인·로그아웃으로 AI 화면이 갱신되지 않음 | 관리자 여부뿐 아니라 UID 변경을 감지하고 탭 상태를 새로 구성 |
| 계정을 바꿔도 이전 계정의 방문한 탭 상태가 남음 | UID별 LazyIndexedStack 키로 기존 탭 폐기 |
| 웹 AI 분석 시작이 모바일 보상형 광고를 요구 | 웹 전용 시작 확인 추가. 기존 서버 인증·일일 쿼터 적용 유지 |
| 웹에서 모바일 구독 화면으로 진입할 수 있음 | 분석 한도 안내와 분석 결과의 구독 유도에서 웹 진입 차단 |
| Facebook 네이티브 플러그인이 웹에서도 호출됨 | 추적·사용자 연결·가입 이벤트에 플랫폼 가드 추가. Firebase 분석은 유지 |
| 비밀번호 재설정이 웹 로그인에 없음 | 재설정 화면, 성공 안내, 이메일 검증 추가 |
| 연속 Enter로 중복 로그인 요청 가능 | 처리 중 제출 차단, 입력 비활성화 |
| 작은 화면에서 로그인 폼이 잘릴 수 있음 | 스크롤, 비밀번호 표시, 자동완성, 인증 오류 안내 개선 |
| 카카오 JS 키가 없는데 로그인 버튼은 노출됨 | 빌드에 키가 없으면 버튼 숨김 |
| Google 웹 신규 가입의 생성일 기록 누락 | 모바일과 동일한 생성일·가입 이벤트 기록 추가 |
| 실시간 지수 메뉴에 시세가 없음 | 6개 항목의 가격·등락률, 개별 로딩·실패 상태, 새로고침 추가 |
| 한글 프록시 응답이 Latin-1 변환에서 실패하며 같은 배치의 해외 지수까지 HTTP 502로 처리됨 | UTF-8 바이트·헤더를 명시하고 개별 응답 실패를 격리. 이미 완료한 요청의 중복 완료 방지 |
| 시황 화면의 KOSPI 이력 요청이 브라우저에서 외부 사이트에 직접 접근 | 기존 Firebase 프록시 경로 사용 및 10초 제한 적용 |
| Flutter 실행 전 빈 화면 | 한국어 로딩 안내, 20초 지연·스크립트 실패 시 재시도, 첫 프레임에서 안내 제거 |

390×720 브라우저에서 메뉴 전환과 로그인 폼, 비밀번호 재설정 전환을 확인했다. 360×360 폼 스크롤은 자동 테스트했다.

## 검증

- 웹 관련 신규 위젯 테스트 9개 통과.
- 기존 검색·지연 탭 생성·시작 광고 초기화 테스트 포함 32개 통과. 이후 추가한 프록시 인코딩 테스트 2개도 통과(총 34개), 지수 테스트 재검증 통과.
- `flutter build web --no-pub` 성공. 최종 인코딩 수정 후 `flutter build web --no-pub --no-wasm-dry-run`도 성공, 지수 테스트 재실행 성공.
- 웹 디렉터리·변경 서비스·신규 웹 테스트 정적 분석은 `No issues found`. 기존 `market_analysis_screen.dart`까지 포함하면 미사용 코드·불필요 null 비교 경고 8개 남음.
- 브라우저에서 새 로딩 안내와 첫 화면 전환 확인. 수정 후 새 네이티브 플러그인 오류는 관찰되지 않음.
- 로컬 HTTP 서버에서 검증했으므로 운영 CDN의 다운로드 속도·최초 방문 시간 개선 수치를 주장하지 않는다.

## 남은 우선순위

1. **카카오 인증 전환 및 기존 계정 보존:** 클라이언트는 카카오 ID에서 유도한 이메일·비밀번호를 사용한다. 서버의 커스텀 토큰 함수는 `kakao:ID` UID를 발급해 기존 이메일 계정 UID와 다르다. 토큰 방식으로 바로 교체하면 기존 저장 데이터·구독과 계정이 분리될 수 있다. 서버에서 검증한 카카오 토큰을 기존 UID에 연결하는 마이그레이션, 기존 비밀번호 로그인 차단과 모바일 호환 전환이 함께 필요하다. 이번 수정은 이 문제를 해결하지 않는다.
2. **외부 데이터 안정성:** 해외 4개 시세 실패의 클라이언트 원인은 한글 응답 인코딩 오류로 확인하고 수정했다. 원본 서버의 응답 지연·실패는 여전히 가능하며 개별 실패 안내와 새로고침으로 대응한다.
3. **데이터 품질:** 경제 캘린더 CPI 중복과 공포·탐욕 데이터 누락은 원본 문서·수집 작업 확인 필요. 시세 공급자별 `marketTime` 시간대 표현도 통일이 필요해 새 지수 목록에는 불확실한 기준 시각을 표시하지 않는다.
4. **주소·뒤로가기:** 메뉴별 URL과 새로고침 후 선택 메뉴 복원이 없다. Router와 게시물 링크 설계를 함께 적용할 후속 과제다.
5. **인증 운영 설정:** Google 승인 도메인, 카카오 키·리다이렉트 설정, 실제 로그인·업로드·공유 동선은 운영 설정을 포함한 검증 필요.

매매일지·포트폴리오·알림·구독 결제 등은 기존 웹 계획에서 의도적으로 제외한 기능이다. 이번 점검에서 단순 누락으로 간주해 추가하지 않았다.
