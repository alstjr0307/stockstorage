# Threads 종목 분석 자동화

첫 문장은 `오늘의 AI종목분석은 {기업이름}이야`로 고정한다. 반말 줄글로 기업의 사업, 실적과 뉴스의 의미, 질문과 답, 위험, 조건별 전망을 설명한다. 마지막에는 `더 많은 종목 분석이 궁금하다면`과 앱 설치 링크를 넣는다.

첫 글은 AI 기업 이미지와 핵심 내용, 분석 점수 카드의 JPEG 두 장을 CAROUSEL로 묶는다. 후속 TEXT 글은 바로 이전 게시물에 답글로 연결한다. 현재 구현은 문단을 보존하여 글당 480자 이하로 나누며, 3~4개로 고정하지 않는다. 사용자가 요청한 3~4개 구성은 본문 압축 또는 장문 첨부 선택 후 반영할 예정이다.

## 구현과 검증

- `threads_editorial.js`: gpt-5.4로 원문 근거가 있는 설명을 생성하고 숫자, 출처, 문체, 깊이, 질문 수 및 인위적 공백을 검증한다.
- `threads_visual.js`: 실제 분석 점수와 날짜를 동적으로 조판한 1080x1350 이미지 두 장을 만든다.
- `threads_graph.js`: 연결 계정 확인, 이미지 컨테이너 처리 대기, 캐러셀 게시와 답글 연결을 수행한다. 게시 응답이 불명확하면 자동 재게시하지 않는다.
- `threads_daily.js`: 당일 Instagram 분석 작업을 재사용한다. 분석은 당일 시장 날짜이며 생성 후 12시간 이내여야 한다. 작업별 잠금과 최대 3회 시도를 적용한다.
- `THREADS_ACCESS_TOKEN`은 Secret Manager에 보관하고 7일이 지나면 갱신을 시도한다.

2026-09-15 검증: 실제 AI 응답 2,961자, 20문단, 질문 4개가 검증을 통과했다. 시작과 마무리를 합친 샘플은 3,141자다. Threads 테스트 10개 통과. 실제 tf_stockstorage 계정에서 이미지 두 장과 캐러셀 컨테이너 FINISHED 상태를 확인했으나 해당 과거 샘플은 게시하지 않았다.

## 운영 상태

Cloud Scheduler는 평일 10~18시, 20분마다 Asia/Seoul 기준으로 실행한다. `_admin/threadsAutomation.enabled`가 true여야 실제 게시한다. 2026-09-15 최신 함수 배포를 확인하고 enabled=true로 활성화했다. 수동 실행 결과 당일 분석이 없어 waiting_for_fresh_analysis가 기록됐다. 실제 최초 게시 성공은 아직 확인되지 않았다. 최신 당일 분석이 없으면 waiting_for_fresh_analysis로 기록하고 기다린다. 부분 게시 또는 응답 불확실 작업은 자동 재실행하지 않으므로 작업 기록의 mediaIds를 확인해야 한다.
