# 종목부터 시작하는 첫 경험 — 2026-10-11

## 적용 내용

- 신규 비회원은 네 장의 기능 설명과 로그인 화면 대신 종목 검색부터 시작한다.
- 검색 결과를 선택하면 홈 위에 해당 종목 상세를 연다. 뒤로 가면 홈으로 돌아온다.
- `먼저 홈 둘러보기`로 검색 없이 진행할 수 있다. 기존 가입자와 온보딩 완료 비회원의 진입은 유지한다.
- 상세에서 관심종목 저장 시 기존 로그인 후 저장 재개 기능을 사용한다. 새 AI 분석의 광고·요금·한도는 변경하지 않는다.
- 공개 홈페이지는 스토어 자동 이동 대신 웹 체험과 각 스토어 링크를 제공한다.
- GitHub Pages 홍보 문구도 관심종목 확인·저장·가격 알림·매매 기록으로 맞췄다.

## 측정 정의

| 이벤트 | 의미 |
| --- | --- |
| onboarding_view | 첫 검색 화면 표시, flow=stock_first_v1 |
| onboarding_complete | 첫 검색 화면에서 이동 결정. action=select_stock 또는 browse. 종목 선택이면 ticker, market 포함 |

완료 이벤트는 상세 데이터 로딩이나 저장 성공을 뜻하지 않는다. 측정 전송 및 로컬 설정 저장 실패는 이동을 막지 않는다. 동일 화면의 중복 클릭으로 완료를 여러 번 처리하지 않는다.

기존 stock_saved, price_alert_created, analysis_view 이벤트를 함께 사용한다. GA4에서는 같은 신규 사용자 집단의 순차 행동으로 계산하고, 이벤트 건수끼리 나누지 않는다. stock_saved는 최초 저장만을 뜻하지 않는다. 첫 방문일을 기준으로 7일 후 재방문을 별도로 비교한다. 공개 홈페이지 링크의 UTM은 웹 유입 구분용이며 스토어 설치 이후까지 연결된다는 의미가 아니다.

## 다음 마케팅 실험

첫 스토어 이미지의 메시지 하나만 바꿔 AI 분석 강조와 관심종목 관리 강조를 비교한다. 종목 콘텐츠의 마지막 장면은 실제 저장·알림 동작으로 구성한다. 인스타그램은 프로필 링크로 안내한다. 캠페인별 저장한 고유 사용자 및 7일 재방문을 비교한 뒤 광고 확대를 판단한다. 현재 성과 수치는 조회하지 않았다.
